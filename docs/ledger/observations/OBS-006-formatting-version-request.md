# OBS-006 - Formatting-Version Request Directed at Frozen Style Canon

## 1. Summary

A colleague requested that the line `## v1.2 formatting pass` be appended to the frozen style guide. The request records a legitimate formatting-version event, but its requested destination is the canon document `REF-STYLE`.

## 2. Finding

The formatting-version event should be recorded in the living ledger rather than treated as an amendment to the frozen design canon. This open observation preserves the request event and links it to `REF-STYLE`, the Documentation Style Guide involved.
